# Languages & Conlangs

Most fictional "languages" are naming languages — enough to generate plausible proper nouns and a few phrases. Full conlangs are a deep craft (Tolkien spent decades on Quenya; Marc Okrand built Klingon as a linguist). Match the depth to the use case.

## Three tiers — pick the right one

1. **Naming language** (a few hours of work) — phonology + naming conventions. Lets you generate consistent names for people, places, things. **This is what most worlds actually need.**
2. **Sketch language** (days to weeks) — phonology + basic grammar + a few hundred words + sample sentences. Lets you write short phrases, inscriptions, snippets of dialogue.
3. **Full conlang** (months to years) — complete grammar, large lexicon, register variation, internal history. Lets you translate arbitrary text. Almost no project actually needs this.

Ask the user which tier they want. If they don't know, default to tier 1 and offer to expand.

## Tier 1: The naming language

This is the highest-leverage layer for almost every world. It takes maybe an hour and pays off forever.

### Phonology — the sound palette

Decide which sounds the language uses and doesn't. The simplest method: list permitted consonants and vowels, then a syllable structure.

**Example (a soft, vowel-heavy language):**
- Consonants: m, n, l, r, s, sh, v, w, y, h
- Vowels: a, e, i, o, u (no diphthongs)
- Syllable: (C)V or (C)VC, where final C is only n, m, l, r, s
- Result: *Anesil, Marevon, Yshalu, Renomir*

**Example (a hard, consonant-clustered language):**
- Consonants: k, t, p, kh, th, g, d, b, ch, ng, ks, st, rk
- Vowels: a, o, u, i (short only)
- Syllable: CCVC or CVCC
- Result: *Krongat, Thurbk, Stargor, Khipkund*

The contrast between languages in a world should be *audible*. If two languages use the same sound palette, they'll feel like dialects, not separate tongues.

### Phonotactic gotchas

- **No language allows all combinations.** Pick what's forbidden and stick to it. ("No language word may start with two stops" or "no word may end in a vowel.")
- **Stress patterns matter.** Always-second-syllable stress (Polish) sounds very different from first-syllable (Finnish) or weight-based (Latin). Pick one.
- **Romanization conventions.** If you write "kh" for /x/, do it everywhere. Decide whether to use diacritics (Tolkien used acute accents; many writers use apostrophes, often unwisely).

### Naming conventions

Decide patterns for each category. These can be cultural (the same language can have different naming styles by class, region, era).

- **Personal names:** patronymic? matronymic? given + clan? given only? bynames earned in adulthood?
- **Place names:** descriptive (Blackwater, Highmarch)? possessive (Garin's Hold)? compound morphemes (Tol-Galen, "green isle")?
- **Titles:** prefixed, suffixed, separate words?
- **Restricted name space:** can commoners use noble-sounding names? Can men use feminine forms?

A handful of root words can generate hundreds of names. Define maybe 30-50 morphemes with meanings and combine them. This makes names feel like they *mean* something to in-world speakers — because they do.

## Tier 2: Sketch language

Add minimal grammar:

- **Word order.** SOV (Japanese, Latin), SVO (English, Mandarin), VSO (Classical Arabic, Welsh)? Pick one and stick to it. Word order has cultural feel — verb-final languages feel more deliberate, verb-initial more dynamic.
- **Morphology type.** Isolating (Mandarin, each word one morpheme), agglutinative (Turkish, Quechua — stack suffixes), fusional (Latin, Russian — endings fuse meaning), polysynthetic (Inuktitut — sentences as single words).
- **Gender / noun class.** None, two, three, sixteen (Bantu languages). Affects everything.
- **Tense/aspect.** Past/present/future, or perfective/imperfective, or no tense at all (Mandarin)?
- **Pronouns.** How many distinctions — formal/informal, inclusive/exclusive "we," gender, animacy?

Build maybe 200-500 words across common semantic fields (body, family, nature, food, war, faith). Write 5-10 sample sentences with morpheme glosses. That's a sketch.

## Tier 3: Full conlang

Only pursue if it's central to the project. Realistically, refer the user to Mark Rosenfelder's *Language Construction Kit* and David J. Peterson's *The Art of Language Invention*. Building a full conlang in a chat session is not realistic; building one *with* a chat assistant over many sessions is reasonable.

## Multiple languages in a world

This is where most worlds get more interesting than their authors planned. Questions:

- **How many languages?** Real continents have hundreds; most fantasy worlds underestimate this.
- **What's the contact history?** Loanwords betray who conquered whom, who traded with whom. (English's Norman French loanwords for prestige items and Anglo-Saxon for the everyday is a classic example.)
- **Lingua franca?** What language do merchants from different regions actually speak? Often a simplified pidgin or a prestige tongue.
- **Sacred / dead languages?** A liturgical language no one speaks natively (Latin, Sanskrit, Classical Arabic, Old Church Slavonic) carries enormous worldbuilding weight.
- **Diglossia.** People often speak one variety at home and another in public. Common in real societies, almost never modeled in fantasy.
- **Script vs. speech.** A writing system can outlast or precede a spoken language. Two languages can share a script (Latin alphabet) or one language can have multiple scripts (Serbo-Croatian).

## Scripts

Even if not designing characters, decide what kind of script:

- **Alphabetic** (Latin, Greek, Cyrillic) — one symbol per phoneme-ish
- **Abjad** (Hebrew, Arabic) — consonants only, vowels marked optionally
- **Abugida** (Devanagari, Ge'ez) — consonant carriers with vowel modifiers
- **Syllabary** (Japanese kana, Cherokee) — one symbol per syllable
- **Logographic** (Chinese, Egyptian) — symbols for words/morphemes
- **Pictographic / ideographic** — symbols for concepts (rare as a primary system)

Script choice affects literacy rates, scribal classes, printing, magic (runes!), and what counts as "writing" in the world.

## Originality moves

- **Build the language around the people.** A nomadic culture's language might be rich in horse / weather / kinship terms and impoverished in agriculture words. A seafaring culture distinguishes a dozen kinds of wave.
- **Encode a taboo.** True names of the dead can't be spoken; the language has elaborate periphrasis. A god's name has no written form. A pronoun is forbidden after dark.
- **Encode a worldview.** Hopi famously (and somewhat mythologized) treats time differently. An invented language where verbs don't distinguish "I did" from "we did" implies a collectivist culture, *and* makes individuating someone's actions linguistically awkward.
- **Sound symbolism.** Cluster the harsh sounds in your "harsh culture" language. Make the priest-caste's dialect use the most softened forms.

## Common pitfalls

- **Apostrophes as flavor.** "K'thal'mar" looks alien but means nothing. Apostrophes should mark glottal stops or syllable breaks, not just *exoticism*.
- **English with funny spellings.** "Drakoria" and "Eldorianos" sound the same as English. Pick a *different* phonology.
- **Inconsistent romanization.** One name spelled with "kh," another with "ch" for the same sound. Pick a system.
- **No internal variation.** All names from one culture sound exactly alike. Real languages have nicknames, formal forms, regional variants, antiquated forms.
- **Forgetting humility.** No language is "more advanced" or "more primitive." Avoid linguistic hierarchies (the "noble tongue" vs. the "barbarian grunt") unless you're deliberately showing in-world prejudice.

## Output format

For a naming-language file:

```
# [Language name] — naming language

## Speakers
Who uses it, where, when.

## Phonology
Consonants, vowels, syllable structure, stress, romanization.

## Forbidden patterns
What never occurs.

## Morpheme set
30-50 roots with meanings.

## Naming conventions
Personal, place, titles, restrictions.

## Sample names
A dozen, with translations where possible.

## Notes
Contact history, dialects, register, etc.
```

For a sketch language, add grammar sections (word order, morphology, key paradigms, sample sentences with glosses).
