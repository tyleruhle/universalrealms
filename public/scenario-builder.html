Stat System

Define which stats characters have. Each archetype will assign bonuses to these stats and each trait pool maps to one stat.

Factions

The political or social groups players can belong to. Each character chooses one at creation.

Archetypes

Character backgrounds that set stat bonuses, personal combat base, and which trait pool they draw from.

Cultures

Regional backgrounds that grant combat traditions and bonus modifiers. Each character picks one.

Traits

Childhood traits drawn from each stat pool during character creation. Each archetype has a primary stat — two traits are randomly awarded from that pool.
